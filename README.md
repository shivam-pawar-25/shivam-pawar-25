### 🚀 Highlight Projects

#### 🛒 **FlashCart – High-Concurrency Flash Sale Backend**
> *Java 21, Spring Boot, Spring Data JPA, MySQL, Redis, Apache Kafka, Docker, JMeter*
- Built to handle thousands of concurrent purchase requests during flash sales.
- **Redis atomic stock management** to prevent overselling under high concurrency.
- **Asynchronous order pipeline via Apache Kafka** to smooth out traffic spikes and minimize latency.
- Idempotency guards and Redis TTL for automatic stock reclamation on unpaid orders.

#### 🧑‍💻 **ClassCode – Institute Coding & Evaluation Platform**
> *Node.js, Express.js, MongoDB, Docker, Redis, AWS, Judge0, Monaco Editor, NGINX*
- Full-stack evaluation platform designed to support **300+ concurrent users**.
- Self-hosted **Judge0 sandbox** running in Docker for secure remote execution.
- Browser-based IDE powered by Monaco Editor with real-time feedback against hidden test suites.
- Asynchronous submission pipeline with Redis job queueing to handle high-traffic submission bursts.
